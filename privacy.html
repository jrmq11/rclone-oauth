Privacy Policy

This application is a personal, non-commercial setup using rclone to access the owner's Google Drive account.

Google Drive Access

The application uses Google OAuth to authorise rclone to access Google Drive. Access is used for file management, transfers and backups initiated by the account owner.

Data Handling

Google Drive data is processed by rclone according to the owner's commands. OAuth tokens are stored in the owner's rclone configuration, not on this website.

Data Sharing

This personal application does not operate a service that sells or shares Google user data with advertisers or third parties.

Website

This website does not intentionally collect visitor information. It is hosted by GitHub Pages, which may process standard website access data.

Contact

For enquiries, please use the contact information associated with the GitHub repository.
